# Zalith Haptic Vibe — Fabric 1.21.1 Mod

Вибрационный мод для **Zalith Launcher 2+** и **PojavLauncher** на Android для Minecraft **1.21.1 Fabric**.
Создан на базе очищенного открытого кода **TouchController**: все сенсорные кнопки, джойстики и оверлеи удалены, оставлен только высокопроизводительный движок тактильной отдачи (haptics) при ломании и установке блоков.

---

## ⚡ Особенности
- **Только вибрация**: никаких лишних виртуальных кнопок на экране, 0% задержек и 0 падений FPS.
- **Ломание блока**: настраиваемая длительность (45 мс по умолчанию) и сила вибрации.
- **Установка блока**: мягкая мгновенная отдача (25 мс по умолчанию).
- **Поддержка Zalith Launcher 2+**: нативное подключение через мост лаунчера или системный Android Vibrator API.
- **Внутриигровое меню настроек**: доступно через ModMenu или файл `.minecraft/config/zalith_vibe.json`.

## 🚀 Как собрать через GitHub Actions за 2 минуты:

1. Создайте новый публичный или приватный репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы этого проекта (или распакуйте скачанный ZIP и выполните `git push`).
3. Перейдите во вкладку **Actions** в вашем репозитории.
4. Выберите workflow **"Build Zalith Haptic Vibe Fabric Mod"** и нажмите **Run workflow** (или он запустится автоматически при пуше).
5. Подождите ~1 минуту. Когда сборка завершится зеленой галочкой, прокрутите вниз в секцию **Artifacts** и скачайте `zalith-vibe-1.21.1-fabric`.
6. Внутри архива будет готовый файл `zalith-vibe-1.21.1-1.0.0.jar`!

---

## 📲 Установка в Zalith Launcher 2+ на Android:

1. Откройте проводник на вашем Android (ZArchiver или встроенный).
2. Переместите скачанный `.jar` файл в папку:
   ```
   /sdcard/Android/data/zalith.launcher/files/.minecraft/mods/
   ```
   *(Или в папку mods вашего выбранного профиля)*
3. Убедитесь, что в лаунчере установлена версия **Minecraft 1.21.1** с **Fabric Loader**.
4. Запустите игру и наслаждайтесь тактильной отдачей при каждом взаимодействии с блоками!

## 🛠 Локальная сборка (если установлен JDK 21):
```bash
./gradlew build
```
